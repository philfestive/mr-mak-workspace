  present workspace; Research keeps unresolved children explicit. Register this
  lab locally and keep unknowns honest. Parent-map repair belongs to its owner.
- **Creative references:** reference and sheet skills require preserved selected
  inputs and review before parts or mesh handoff. Keep parent revisions and input
  identities. The Arachne sample does not establish an approved personal design.
- **Geometry and motion:** production skills distinguish editable source,
  export checks and actual engine behavior. Keep selections scoped to their

- **UI and integrity:** card search does not search character records, and the
  existing verifier checks only listed files. Add catalog search and a managed
  tree inventory while reusing that verifier for exact bytes.
- **Adversarial review:** linked files can refer to the wrong revision or a
  changed manifest. Pin evidence bytes and bind review and selection to the

## Rules that keep useful work moving

Save results in their assigned revision, register them, review the exact input
and output, then update the existing task. Do not create a new LATEST or CURRENT
document to describe a fact the catalog already owns. Reuse the existing
integrity verifier. Stop duplicate paid submissions by assigning one job-recovery
owner. Keep a rejected take and its reason instead of losing the design history.

Required media and editable sources need an explicit retention location. An
ignored asset is not preserved by a Git commit, and another drive in the same
PC does not establish an independent backup. No backup or archive operation was
performed by this setup.

The lab check is a manual handoff check, not automatic enforcement or continuous
monitoring. Passing it proves registration and stable recorded bytes only.
Owner design selection and actual engine verification remain separate evidence.
