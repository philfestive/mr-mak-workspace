# Workspace Home

This workspace is your **Refiner**: bring in selected lessons, question ideas,
define the GDD, index and schemas, then implement a clearly chosen project.
You are the solo developer; AI agents help refine and document your decisions.

Start with [Intake](#/team-hub/5). [Build focus](#/team-hub/6) owns the implementation
selection and links to the chosen design. You chose Refiner setup first and game
selection afterward. Existing support work remains on its own task records.

Codex asks focused question rounds. Mr. Mak asks one at a time in voice; final
choices are saved in the same project documents used for implementation.

## Where the truth lives

| Information | Authoritative source |
| --- | --- |
| About you and your preferences | `context/identity.md` and `context/preferences.md` |
| Current goals | `context/goals.md` |
| Ideas and selected source references | [Intake](#/team-hub/5) |
| Project selected to implement | [Build focus](#/team-hub/6) |
| Project brief and specifications | The project's README and linked source files |
| Current work and next actions | [Tasks](#/team-hub/2) |
| Choices and their reasons | [Decisions](#/team-hub/3) |
| Progress and verification notes | [Notes](#/team-hub/4) |

[Projects](#/team-hub/1) is a directory to the project sources. It links to briefs
instead of copying them. Tasks owns current status; Notes records evidence.
Update the owning source and link to it elsewhere.

## A short working loop

1. Capture a named idea or source and ask the next design questions.
2. Record decided answers in the GDD; define its index and schema contracts.
3. Select the project and first slice in Build focus when you are ready.
4. Implement that defined slice, check it and link the results.

Use one folder and card per project, with tabs for related revisions. A roster
or coordinator appointment is not required. If several assistants work at once,
give them separate edit scopes and one writer per shared file.

In a narrow window, use **Hide menu** for reading space. The maintained workflow
is `processes/workspace-organization.md`.

The existing card ID stays stable. On this PC, the legacy folder path points to these same
files through a local junction. Git saves only the canonical Home folder; a
fresh clone uses the canonical paths without recreating that compatibility link.
