# Character Lab

Read the repository rules first. The only lab reading order is:
1. `README.md` for scope and authority.
2. Workspace Home `tasks.md` for the assigned task and exact write set.
3. `workspace/2026-10-12_character-lab/catalog.json` for character and revision identity.

One writer owns the catalog and shared navigation during an assignment. Workers
write only their assigned character/revision folder. Reviewers read sources and
return findings to that writer. A review team is temporary; do not invent a
permanent roster or new board.

Preserve inputs and earlier revisions. Register each new file in its revision's
delivery manifest or evidence references. Update existing authorities rather
than creating alternate CURRENT, LATEST, STATUS or handoff indexes.

Run `node scripts/check-character-lab.mjs` from the repository root before
handoff. A passing index check establishes file integrity and registration;
visual selection and engine behavior need their own evidence. No provider,
model, budget, engine or paid generation is selected by this setup.
