# Human/cartoon - first style refinement

Status: Refining. Selected first by the owner, 2026-10-12.
This file owns Human/cartoon-specific questions and answers for this Refiner.
Shared device/FPS/direction choices live in [design direction](../design-direction.md).
No game, asset, palette, shader or production style has been selected by naming
this topic. Legacy Arty bright_cartoon is a candidate reference mapping.

## What we know

- Start with Human/cartoon and use earlier style ideas as inputs.
- Begin with environment props, starting from a crate or signpost discussion.
- Pursue painted matte cartoon surfaces with soft edges. The edge technique,
  palette, lighting and precise geometry remain open.
- Define the visible specifics one at a time rather than importing an old style
  package or its numerical rules.
- Preserve the performance-first mobile direction. Pixel 9 Pro XL is the
  reference phone; mid-range Android support and later iPhone remain the goal.

## Source ideas to discuss

Explorer [38's source map](../tasks/macro-review/reviews/38-human-style-sources.md)
identifies broad rounded masses, clear silhouettes, a few meaningful practical
parts, large material-role groups and color-preserving darker variants in earlier
Human work. These are ideas to judge, not answers selected for this new philosophy.

The authored crate, generated crate, signpost image study and later signpost
mesh package have different identities and evidence. Use their exact source
records and ask which property matters. SHAR v2 amendments override inherited
research thresholds in that source; none becomes this profile's palette budget.
