# Working preferences

Confirmed organization preference and existing workspace defaults:

- Organization: use Workspace Home as the starting point, with clear names and
  one authoritative source for each kind of information. Keep the process useful
  for a solo developer working with AI assistants.
- Refinement: ask many focused questions in rounds before building. Keep to the
  GDD and define the documented index and schemas first.
- Reuse: bring forward named lessons and specific materials from earlier work;
  preserve source locations rather than copying whole projects.
- Final input: use Codex questions and Mr. Mak conversations; save explicit
  choices in the same authoritative documents and keep unresolved answers visible.
- Stored content: English unless explicitly requested otherwise.
- Communication: clear, practical updates and visible results.
- Reports: shared Workspace styling, readable tabs, image enlargement and downloads.
- Navigation: open internal documents in Workspace previews. Explore grouped
  sub-tabs for related material.
- Changes: keep revisions together and record what was checked.
- Permissions: choose the level appropriate for each task; do not infer a personal
  preference for bypassing approvals from the examples.
- Restarts: ask before interrupting a running application or agent chat.
